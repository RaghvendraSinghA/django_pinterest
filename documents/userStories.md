# User Stories — Pinterest

## 1. Design Uploader

### US-01: Upload a Design
As a design creator, I want to upload an image so that I can share my design with other users.

### US-02: Add Design Details
As a design creator, I want to add a title and description to my design so that viewers can understand what it is about.

### US-03: Organize Designs
As a design creator, I want to save my uploaded designs to boards so that I can organize my content.

### US-04: Edit a Design
As a design creator, I want to edit the details of my uploaded design so that I can keep the information up to date.

### US-05: Delete a Design
As a design creator, I want to delete my uploaded design so that I can remove content I no longer want to share.

### US-06: View Engagement
As a design creator, I want to see likes and comments on my designs so that I can understand how users interact with my content.

### US-07: Interact with Viewers
As a design creator, I want to respond to comments on my designs so that I can interact with my audience.

---

## 2. Design Viewer

### US-08: Browse Designs
As a viewer, I want to browse different designs so that I can discover ideas and inspiration.

### US-09: Search for Designs
As a viewer, I want to search for designs using keywords so that I can find content related to my interests.

### US-10: View Design
As a viewer, I want to open a design and view its details so that I can understand the content.

### US-11: Like a Design
As a viewer, I want to like a design so that I can show appreciation for the content.

### US-12: Save a Design
As a viewer, I want to save a design to a board so that I can access it later.

### US-13: Organize Saved Designs
As a viewer, I want to organize saved designs into different boards so that I can easily find them later.

### US-14: Comment on a Design
As a viewer, I want to comment on a design so that I can share my thoughts and interact with other users.

### US-15: Follow a Creator
As a viewer, I want to follow creators whose designs I like so that I can discover their future content.

### US-16: View Personalized Content
As a viewer, I want to see designs related to my interests so that I can discover relevant ideas more easily.

### US-17: Share a Design
As a viewer, I want to share a design with others so that I can recommend interesting content to them.
